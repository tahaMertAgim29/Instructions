# Linux Virtual Machine Setup

## Introduction

This is the instruction file for Ubuntu-Linux Setup as Virtual Machine using VirtualBox in Windows.
You could also use VMWare but VirtualBox is used in this instruction so the steps will be followed based on VirtualBox.

## Requriements

- VirtualBox
- Ubuntu LTS 24.04.4
- Windows

> [!WARNING]
> Ubuntu Version and VirtualBox version may not support each other depending on technology versions.
> This is experienced during installation and setup. Therefore, these versions were used during setup and installations.
> You have potential to encounter with some problems so that you should advice AI tools when you experience those issues

> [!NOTE]
> If you do not have the requirements, you could download them above the links:
>
> [VirtualBox Download](https://www.virtualbox.org/) (You should choose the right one depending on your computer or system)
>
> [Ubuntu Desktop LTS](https://releases.ubuntu.com/noble/) (You could choose which release you want to setup your computer)

## Setup and Installation Steps

1 - Go to the website (https://releases.ubuntu.com/noble/)

2 - Choose the Desktop Image to download on the website. After that, you will see a file with `.iso`.

**3 - Create a new virtual machine and set CPU, RAM and virtual disk capacity from VirtualBox.**

4 - Open the VirtualBox and click `New` to create a new VM and put the `.iso` image. After that, set CPU, RAM and Hard Disk.
![Creating a new VM](https://www.virtualbox.org/manual/images/create-vm-1.png)

5 - Start the Virtual Machine and then click `Try or Install Ubuntu`

6 - Choose the Language for your Ubuntu
![Choosing Language](https://ubuntu.com/desktop/docs/en/24.04/_images/choose-your-language.jpeg)

7 - Skip the Accesbility Section unless necessary (Click next)

8 - Choose the keyboard language/layout
![Choosing keyboard language](https://ubuntu.com/desktop/docs/en/24.04/_images/keyboard-layout.jpeg)

9 - Connect to the Internet
![Setting up the connection](https://ubuntu.com/desktop/docs/en/24.04/_images/internet-connection.jpeg)

10 - Choose to install Ubuntu
![Try or Install Ubuntu](https://ubuntu.com/desktop/docs/en/latest/_images/try-or-install-ubuntu.png)

11 - Settings (Skip without changing unless necessary) 
> [!NOTE]
> You could follow the other steps without modifying the default settings. However, it depends on what you to do with Ubuntu or what you to do with those settings


12 - Create Your Account for Ubuntu
![Create Account](https://ubuntu.com/desktop/docs/en/24.04/_images/create-your-account.jpeg)


13 - Select the timezone
![Timezone](https://ubuntu.com/desktop/docs/en/24.04/_images/select-your-timezone.jpeg)

14 - Install Ubuntu
Ubuntu is ready to install now. Click the install button
![Install Ubuntu](https://ubuntu.com/desktop/docs/en/24.04/_images/ready-to-install.jpeg)

15 - After that, Ubuntu will be installed
> [!WARNING]
> If you encounter with a problem during the installation. You should take advice from AI bots to solve the problems, because the problems might be complicated to solve without advising AI.
