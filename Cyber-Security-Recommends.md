# Cyber-Security-Recommends

## Introduction

This is a recommendation to improve yourself on Cyber Security.

> [!IMPORTANT]
> When you want to be expert in Cyber Security, you should make your infrastructure for Cyber Security hard, meaning that your fundamentals to Cyber Security must be very good

## Requirements

To understand Cyber Security better on later steps, you need these topics first as fundamentals.

1. Networking Basics
2. Operating System Fundamentals (Windows generally)
3. Linux Fundamentals
4. Command Line Fundamentals
5. Computer Fundamentals
