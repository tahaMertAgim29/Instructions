# NodeJS, NPM & Package Installation

## Introduction

This is an instruction about how to install packets(libraries) using NPM (Node Package Manager)

## Prerequisities
- NodeJS
- NPM
- Visual Studio Code (Instructions will be explained using VSCode)

>[!NOTE]
> Before following the instruction steps, please ensure that you have already completed downloadings of NodeJS and VSCode.
> If you have not, then, you could check these sites/videos to download below for both NodeJS/NPM and Visual Studio Code:
>
>`Visual Studio Code:` https://code.visualstudio.com/download
>
> `NodeJS and NPM:` https://www.youtube.com/watch?v=kQabFyl9r9I
 
>[!WARNING]
> When you downloaded Visual Studio Code, NodeJS and NPM, ensure that they work properly and there is no error.
> Also ensure that you installed the required packs for these 

# Instructions

1. Open an project in Visual Studio Code
> To open a folder in VSCode, choose File from upper left menu, press New Folder and choose your folder

>[!TIP]
> You can create a folder from File Explorer and open the folder from Visual Studio Code

2. Open a terminal in Visual Studio Code
> from upper left menu by choosing Terminal and press New Terminal and you see a terminal on the main page below

3. Creating package.json. To create it, enter this command into the terminal: 
```
npm init -y
```
4. Then check whether `package.json` has been created or not. You should also see those below:
```
node_modules/
package.json
package-lock.json
```

6. Creating the package you want to install. To create the package, enter this command into the terminal:
```
npm install `package`
```
